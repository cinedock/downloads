# Kinostrata downloads

Official downloads for Kinostrata, formerly CineDock. Step-by-step install for every device: [kinostrata.com/setup](https://kinostrata.com/setup).

| Device | What to install |
|---|---|
| Fire TV, NVIDIA Shield | **Kinostrata TV**: [kinostrata.com/apk](https://kinostrata.com/apk) always gives the current version. Install over an existing app. |
| Zidoo | **Kinostrata Zidoo** and **Kinostrata Playback Helper**, a pair from the newest `zidoo-v…` release: install the helper first. |
| Windows, Mac | **Kinostrata Desktop** from the newest `desktop-v…` release. |
| Server or NAS | The container `ghcr.io/cinedock/cinedock` (Unraid, TrueNAS, Docker). |

Every file has a SHA-256 checksum beside it on its release page. The TV apps are release-signed with the same key as before, so each installs over the existing version; never uninstall first. The files keep their CineDock names so existing installs keep updating.

The desktop builds are not yet code-signed. Windows may show a SmartScreen warning. On a Mac, Control-click `Kinostrata.app`, choose **Open** and confirm; never disable Gatekeeper.
